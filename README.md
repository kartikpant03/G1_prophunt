# PropHunt Game
This the First Multiplayer Game I have Developed. In this game, you have to hide as a prop and the seeker will try to find you as a hidden prop in the map.
This is a multiplater game in which the person can Host a game server and make public and private lobbies which the other players can Join.
It also consists of a Voice Chat room which the player can talk other people in the lobby.
